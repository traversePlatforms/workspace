# drafts/social-kit — Surge social media kit

Profile pictures and banners for **LinkedIn, Facebook, Instagram, X, Nextdoor,
YouTube and Google Business Profile**, plus Instagram Story-Highlight covers.
One visual system across all of them.

- **[UPLOAD-GUIDE.md](UPLOAD-GUIDE.md)** — which file goes in which field, platform
  by platform. Start here.
- **[out/](out/)** — the 22 PNGs. **[out/review.html](out/review.html)** shows them
  all with labels.
- **[build-social.mjs](build-social.mjs)** — the generator. `node build-social.mjs`
  (needs Chrome). One artwork definition → every size re-exports consistently.

**Draft & stage only — nothing uploaded or posted.** The design system:
`#0a0a0a` ground, ascending-bars mark in brand green `#4abe4a`, the traced Surge
wordmark, mono descriptor "Outsourced sales & marketing", green baseline rule.
Palette and wordmark per `brand/guidelines/README.md` and `brand/logos/`.
Clearance notes are in the upload guide.
