Review card

Before printing a batch: print the size you’ll actually use and scan it with two or three phones. Keep the code dark on a light background — low-contrast colour combinations may not scan. Leave a clear border around it.

SVG is best for a print shop (scales to any size). PNG is fine for digital use and small prints. The badge covers part of the code — it is built with high error correction so it still reads, but the plain version (badge off) is the safe fallback.
