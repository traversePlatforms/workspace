# drafts/social-kit-wordmark — Surge social kit, wordmark only

The **interim** Surge social kit: identical to [../social-kit/](../social-kit/)
in palette (brand green kept), dimensions, layout and file list, but with the
**added three-bar mark removed everywhere**. Just the default Surge wordmark on
the dark ground, with a green baseline rule + faint green glow on the banners.

Use this while the bar mark is being confirmed with your boss. Switch to
`../social-kit/` once it's approved — the mark is the only difference.

- **[UPLOAD-GUIDE.md](UPLOAD-GUIDE.md)** — which file → which field, per platform.
  Read the note about avatars: the wordmark has no square form, so profile
  pictures read well at normal size and get small very small — that's the gap the
  pending mark fills.
- **[out/](out/)** — 22 PNGs (`surge-wm-*`). **[out/review.html](out/review.html)**
  shows them all with labels.
- **[build-social.mjs](build-social.mjs)** — generator. `node build-social.mjs`
  (needs Chrome).

**Draft & stage only — nothing uploaded or posted.**
