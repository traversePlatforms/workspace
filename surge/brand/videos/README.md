# Videos

**I cannot watch video.** No frames, no audio, no transcript. This folder is storage, not something I can read.

That's a real limit worth knowing before you spend time filing clips here expecting me to use them.

## What I can still do

- **Work from a transcript.** Put one in `brand/notes/` and I'll treat it as source material like any other note — pull quotes, build a post, check claims.
- **Work from your description.** Tell me what's in a clip and I'll write around it.
- **Use a still.** Export a frame to `brand/photos/` and I can see that.
- **Hand a URL to Blotato.** Its video templates take video URLs, so a hosted clip can be fed into one. I still won't know what's in it.

## If you want video content made

Blotato has AI video templates — narrated stories, avatar videos, slideshow-to-video. Those generate from a script rather than from your footage. Same caution as the image templates: the prompt-driven ones invent content, so anything factual needs checking frame by frame, and I can't check a video by watching it. Realistically that means keeping any generated video's script tightly scoped to text I wrote.

## Naming

If you do store clips here, name them for what they contain and add a line to `videos-notes.md`. It's the only way I'll know a clip exists or what's in it.

## Start at `videos-notes.md`

It's the inventory — 17 clips, ~3.05 GB, all unwatched. The folder listing tells you filenames; the inventory tells you what is known about them, which clusters they probably belong to, and why training-floor footage should be assumed restricted until a specific clip is checked.
