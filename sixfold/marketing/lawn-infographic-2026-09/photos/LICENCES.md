# Licence receipts

One line per file, filled in when the file lands. Nobody can reconstruct this two years
later, and "where did this picture come from" is exactly the question that gets asked when
an ad runs for a while.

| File | Source | Asset ID | Licence | Date | Licensed to |
|---|---|---|---|---|---|
| | | | | | |

**Adobe Stock:** the asset ID is the number in the filename — `AdobeStock_1234567890.jpeg`.
The licence type is **Standard** for this use. Keep the invoice; the ID alone is not proof
of licence, it is proof of which picture.

**A watermarked preview is not a licensed file.** Adobe lets you download a free comp to
try in a layout. It carries a visible watermark and it may not be published. If a frame in
`lawn-photo.png` has a diagonal mark across it, that is what happened.
