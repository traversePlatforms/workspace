2 Three ways to get a job done

💻At the laptop
  1. Open VS Code, File → Open Recent → jarvis-cloud.
  2. Ask Claude, same as now.
  3. It edits, tests and deploys on the cloud machine.
First time only: Ctrl+Shift+P → Remote-SSH: Connect to Host → jarvis-cloud → open /home/yard/main.
📱From your phone
  1. Open J.A.R.V.I.S.
  2. Type or say the request.
  3. The cloud machine does it right away, laptop on or off.
After the switch there’s no more 15-minute wait for code changes.
☁Long jobs
  1. Data runs, big builds, uploads start in the background.
  2. Close the laptop if you like.
  3. Watch the ring on the globe; your phone gets an alert when it’s done.
Our chat pauses while you’re disconnected; the job doesn’t.

6 If something looks wrong

“Stuck” alert on your phoneJ.A.R.V.I.S.’s change clashed with one of ours. Nothing is lost: it’s parked, and I sort it out in a session.
A deploy says “refused”The two copies need to catch up first. It fixes itself within 2 minutes, or I run the sync.
VS Code says “reconnecting”Wi-Fi blip. It reconnects on its own; background jobs never stopped.
Anything elseRun the undo above, or ask me. The laptop copy is kept as it was at the switch.
