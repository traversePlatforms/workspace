Assistant: privacy

Last updated 22 October 2026

Assistant is a private tool that Matthew Sharpe built for his own use. It sorts his own email accounts and writes reply drafts for him to review. It is not offered to the public, and only accounts he owns connect to it.

What it reads

When an inbox is connected with Google sign-in, Assistant reads new emails in that inbox: the sender, the recipients, the subject, the date and the text. It uses Gmail's gmail.modify permission. That permission lets it read mail and write drafts. Assistant never sends email and never deletes it.

What it does with it

  • Each new email is sent to Anthropic's Claude API to be sorted: needs a reply, to do, for information, receipt, and so on. Where a reply is wanted, Claude writes a draft, which Assistant saves to that inbox's Gmail drafts for Matthew to edit and send himself.
  • Assistant keeps only a short summary of each email (who it is from, the subject, one line about it and how it was sorted) for 21 days. The email itself stays in Gmail.
  • Google sign-in tokens and the other keys are kept in a private folder on Assistant's own server. They are not shown on any page.

What it never does

  • It does not sell, share or give away any email data, and it does not use it for advertising.
  • No person reads the email data except Matthew, for his own accounts.
  • Assistant's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Disconnecting an inbox in Assistant deletes its sign-in token. Access can also be removed at any time from the Google account's security settings (Third-party apps with account access). Stored summaries are deleted after 21 days.
