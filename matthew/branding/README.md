## The identity, as it stands

Name-independent, so it carries over:

- **Mark A of three** — a dead-true line over a crooked one, anchored by two pins. It draws the
  difference between a checked claim and an unchecked one, which is the offering. B (a chalk burst) and
  C (a graduated datum) illustrate a tool instead, and were not recommended.
- **Animation rule** — the line is *pulled taut*: it draws from the left pin to the right over 0.62s on
  an overshooting curve, the far pin seats, fires once. Never a generic fade; the rate card promises a
  defined rule per mark.
- **Palette, taken from chalk-line chalk** — blue is the real temporary layout colour, red the
  permanent one:

  | Token | Hex | Role |
  |---|---|---|
  | Chalk Blue | `#1E5AC8` | Primary. The line. |
  | Chalk Dust | `#B9CCEE` | Tints, fills, print texture |
  | Graphite | `#171B21` | Text and dark ground |
  | Slate | `#5C6673` | Secondary text, the crooked line |
  | Paper | `#EEF0F3` | Light ground |
  | Red Chalk | `#B03A2A` | Corrections only. Never decoration. |

  Blue was chosen partly because it collides with neither **Surge** (green on near-black) nor
  **Sixfold** (ember on pine), so the three never get confused.
- **Type** — Archivo display / IBM Plex Sans body / IBM Plex Mono for figures and sources. The mono
  role is not decorative: a studio whose deliverables all carry a fact-check log needs a face that
  makes a source table read as evidence.
- **Register**, decided 2026-09-13 — **a named studio, honest that it is solo.** Brand name up front
  for credibility against agencies, first person "I" in the copy, no implied headcount. Claiming a team
  he does not have would undercut the verifiability being sold, and
  [../services-pricing.md](../services-pricing.md) §6 bars overclaiming.
